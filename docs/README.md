# Documentos de marca

- **`Manual-de-marca-Arroyo-Guzman.pdf`**: manual de marca y sistema de diseño (A4, 17 páginas).
  Se regenera con `python3 docs/manual/construir.py`. Requiere Chromium y Playwright para Node, y lee `design-system/` y `docs/img/`.
- **Presentación** (marca, sistema de diseño y sitio web, 21 diapositivas): https://claude.ai/artifact/Kc5hZ7J6b226V6jTWw8prL
  Se descarga como PowerPoint o PDF desde el menú de la presentación. El código de las diapositivas está en `presentacion/`.
- **`img/`**: capturas de las plantillas y del sitio que usan el manual y la presentación.
